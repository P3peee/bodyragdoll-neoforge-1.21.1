# Bodycam Ragdoll (NeoForge 1.21.1)

Рэгдолл-трупы как в Bodycam + крики + интеграция с TaCZ.

## Что делает
- При смерти игрока/моба вместо ванильного падения создаётся труп-сущность и включается физика рэгдолла
  (голова, торс, руки, ноги — verlet-скелет, коллизии с блоками, трение, засыпание).
- Труп — реальная сущность на сервере: **остаётся в мире, сохраняется при рестарте, виден всем игрокам рядом**.
  Физика детерминирована, поэтому у всех тело лежит одинаково; зашедшие позже "догоняют" симуляцию.
- Крик при уроне (с паузой) и при смерти. У каждого свой тон голоса (по UUID).
- TaCZ: событие убийства из оружия (через рефлексию, TaCZ не нужен для сборки) даёт направление выстрела,
  хэдшот бьёт по голове сильнее. Без TaCZ направление берётся из урона / полёта снаряда.
- Скин игрока берётся из TabList (если игрок онлайн), иначе дефолтный скин.

## Сборка
1. Проще всего: скачай MDK для NeoForge 1.21.1 (https://github.com/neoforged/MDK), скопируй из этого архива `src/` внутрь,
   подправь `gradle.properties`.
   Либо в этой папке выполни `gradle wrapper --gradle-version 8.10`, затем `./gradlew build`.
2. Готовый jar: `build/libs/bodyragdoll-1.0.0.jar` → в папку `mods`.
3. Нужен JDK 21. Версию NeoForge (`neo_version`) можно поднять до последней 21.1.x.

## Свои крики
По умолчанию используются ванильные звуки (кричащая коза, гаст, житель) — файлов .ogg в архиве нет.
Положи свои .ogg в `assets/bodyragdoll/sounds/scream/` и замени записи в `assets/bodyragdoll/sounds.json`:
`{ "name": "bodyragdoll:scream/hurt_1" }` (без `.ogg`, без `"type": "event"`).

## Конфиг (`config/bodyragdoll-common.toml`)
maxCorpses, corpseLifetimeSeconds (0 = навсегда), impulseStrength, screams, screamAllMobs, screamVolume, blacklist.

## Ограничения
- Броня и предметы в руках на рэгдолле не рисуются.
- Рэгдолл (части тела) — для гуманоидов (игроки, зомби, скелеты, пиглины...). Остальные мобы лежат на боку и немного скользят.
- Код написан без возможности собрать/запустить в среде генерации — возможны мелкие правки при первой сборке.
